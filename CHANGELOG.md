## [1.2.0] — 2026-06-16 — Кастомизация дизайна веб-интерфейса

### Описание
Реализована кастомизация дизайна вебстраницы библиотеки Settings **без модификации самой библиотеки**. Использован хук `/custom.js` для подгрузки пользовательских CSS-стилей на веб-страницу.

### Что сделано

#### Новые файлы
- **`data/custom.js`** — файл с кастомными CSS-стилями в формате JavaScript-класса со статическим свойством `css`. 
  - Формат: `class _ { static css = \`...\`; }` — корректно обрабатывается функцией `registerCustom()` в Settings-web
  - CSS-переменные (`--accent`, `--back`, `--tab` и т.д.) переопределяют стандартную тему
  - Дополнительные CSS-правила переопределяют стили кнопок, слайдеров, переключателей и др.

#### Изменённые файлы
- **`src/web_server.cpp`** — добавлена регистрация `custom.js` через `sett.setCustomFile("/custom.js")` (если файл существует на LittleFS)
- **`platformio.ini`** — добавлены `upload_flags` (`--before no_reset --after no_reset`) для корректной загрузки на ESP32-S2

### Архитектура кастомизации
```
ESP32 старта → проверяет /custom.js на LittleFS → вычисляет hash
    ↓
Браузер → загружает страницу → сервер отправляет custom_hash
    ↓
Клиент сравнивает hash → если отличается → загружает /custom.js
    ↓
Сохраняет в localStorage → перезагружает страницу
    ↓
registerCustom() парсит JS класс → извлекает .css → вставляет <style> в <head>
```

### Как загрузить на плату
```bash
# Шаг 1: Данные (custom.js + stations.txt) на LittleFS
pio run -e lolin_s2_mini -t uploadfs --upload-port COMx

# Шаг 2: Прошивка
pio run -e lolin_s2_mini -t upload --upload-port COMx
```

Или через веб-интерфейс: ☰ → файловый менеджер → загрузить `data/custom.js` в корень (`/`).

### Как изменить дизайн
1. Отредактировать `data/custom.js`
2. Загрузить на устройство (веб-интерфейс или `pio run -t uploadfs`)
3. **Очистить кэш браузера** (Ctrl+Shift+Delete) — обязательно, т.к. библиотека кеширует файл в localStorage
4. Перезагрузить страницу

### Ход работ
Процесс включал несколько итераций:
- Изучение того, как библиотека Settings отдаёт веб-страницы (gzipped PROGMEM bytes)
- Изучение механизма `/custom.js` в коде Settings-web
- Первая попытка: JS-обёртка с `(function(){...})()` — ошибка парсинга
- Вторая попытка: чистый CSS — ошибка парсинга
- Третья попытка: формат JS-класса `class _ { static css = \`...\`; }` — **работает**
- Скачан и изучен исходный код [Settings-web](https://github.com/GyverLibs/Settings-web) для верификации формата
